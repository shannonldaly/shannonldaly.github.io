Music Co-Pilot (Rubato)

A music production copilot built as a multi-agent system. Type a mood, a genre, or an artist reference and get a validated chord progression with Ableton instructions, a theory explanation, and an audio preview. It's the scratchpad for the skeleton of your song, and when you like the starting point, one click sends it into Ableton.

I built it around the pain point I kept hitting while learning music production. Starting a song from scratch in a DAW means facing too many choices about the skeleton of the song at once, and then transposing every idea into the right key by hand. Rubato is the scratchpad that comes before Ableton: you settle the progression, the melody direction, the bass, and the drums one decision at a time, and then send the whole thing over.

How it works

The Orchestrator receives every request, detects intent, routes to the minimum set of agents needed, and assembles a structured response. Theory output is validated by music21 before it ever reaches the user, so the progressions are checked by a deterministic quality gate, not vibes. Every agent call is logged with structured fields.

Theory Agent + Validator

Chord progressions with alternatives and melody direction, validated deterministically by music21. The validator is not an LLM. It's a quality gate.

Production Agent

Step-by-step Ableton Live 12 instructions, and over MCP the whole arrangement lands in a live Ableton set as named tracks with instruments loaded, immediately playable.

Teaching Agent

Explains the why. Sonnet API when a key is available, local templates as the fallback, so the app works at $0.

Sound Engineering Agent

Mixing, EQ, compression, sidechain. Nine local topics with API fallback.
