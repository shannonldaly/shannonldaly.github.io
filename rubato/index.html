Music Co-Pilot (Rubato)

An AI-powered music production assistant built as a multi-agent system. Type a mood, genre, or artist reference and get a validated chord progression with Ableton instructions, a theory explanation, and audio preview. Not Suno. This doesn't generate music for you. It amplifies your ability to generate music yourself.

I built it around a pain point I hit while learning music production: Claude kept hallucinating chord progressions, and I wanted help that was actually correct.

How it works

The Orchestrator receives every request, detects intent, routes to the minimum set of agents needed, and assembles a structured response. Theory output is validated by music21 before it ever reaches the user, so the progressions are checked by a deterministic quality gate, not vibes. Every agent call is logged with structured fields.

Theory Agent + Validator

Chord progressions with alternatives and melody direction, validated deterministically by music21. The validator is not an LLM. It's a quality gate.

Production Agent

Step-by-step Ableton Live 12 instructions, and over MCP the chords land directly in a live Ableton set with a pad instrument auto-loaded, immediately playable.

Teaching Agent

Explains the why. Sonnet API when a key is available, local templates as the fallback, so the app works at $0.

Sound Engineering Agent

Mixing, EQ, compression, sidechain. Nine local topics with API fallback.

Watch it work

The core loop, recorded against the running app: pick a session mode, type "melancholic lo-fi in A minor," and get a validated progression back in seconds. Watch the agent pipeline across the top go green, the music21 check pass, and the Send to Ableton button light up.

The full loop goes one step further: Send to Ableton pushes the chords over MCP into a live set with a pad instrument auto-loaded, immediately playable. That clip lands when Rubato comes off pause.
